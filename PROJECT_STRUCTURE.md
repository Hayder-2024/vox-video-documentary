# Vox Video Documentary Project Structure

## 📁 Project Organization

```
vox-video-documentary/
├── 📄 README.md                    # Project overview
├── 📄 CONCEPT.md                   # Story concept & pitch
├── 📄 SCRIPT.md                    # Full documentary script
│
├── 📂 research/
│   ├── sources.md                  # Cited sources & references
│   ├── data.md                     # Statistics & facts
│   └── interviews.md               # Interview notes & quotes
│
├── 📂 production/
│   ├── shot_list.md                # Detailed shot list
│   ├── storyboard.md               # Visual storyboard breakdown
│   ├── shooting_schedule.md        # Timeline & logistics
│   └── locations.md                # Location scouting notes
│
├── 📂 graphics/
│   ├── animations.md               # Animation concepts
│   ├── graphics_list.md            # Charts, maps, infographics
│   └── design_notes.md             # Visual style guide
│
├── 📂 audio/
│   ├── narration.md                # Narration script (separate)
│   ├── music_list.md               # Music & sound effects
│   └── audio_notes.md              # Technical audio specs
│
├── 📂 editing/
│   ├── cut_notes.md                # Edit decisions & timing
│   ├── color_grade.md              # Color grading notes
│   └── effects.md                  # Visual effects list
│
└── 📂 assets/
    ├── references/                 # Inspiration & reference videos
    ├── thumbnails/                 # Thumbnail concepts
    └── metadata.md                 # YouTube SEO & descriptions
```

## 🎬 Typical Vox Video Structure

1. **Hook (0-5 sec)** - Compelling question or visual
2. **Problem Setup (0:05-1:00)** - Context & stakes
3. **Narrative Development (1:00-5:00)** - Deep dive with evidence
4. **Twist/Insight (5:00-7:00)** - Key revelation
5. **Resolution (7:00-8:30)** - Takeaway & why it matters

## 📝 Key Files to Create

- **CONCEPT.md** - What's your documentary about?
- **SCRIPT.md** - Full narration & scene descriptions
- **research/** - All your sources & data
- **production/** - How you'll shoot it
- **graphics/** - Visual explainers & animations
